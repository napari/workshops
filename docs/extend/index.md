**Level:** Intermediate | **Duration:** ~4 hours | **Python required**

This workshop teaches you how to extend napari's functionality through scripting
and custom code. You will use Python to load and visualize image data, set
physical scales and units, work with metadata with Xarray and Zarr,
create interactive widgets with magicgui, respond to layer events and mouse
interactions, and package your custom tools as pip-installable napari plugins.
