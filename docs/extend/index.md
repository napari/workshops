**Level:** Intermediate | **Duration:** ~4.5 hours | **Python required**

This workshop teaches you how to extend napari's functionality through scripting
and custom code. You'll learn your way around the napari GUI, control the viewer
from Python, set physical scales and units, work with cloud-native formats like
OME-Zarr, build interactive widgets with magicgui, respond to layer events and
mouse interactions, and package your custom tools as pip-installable napari plugins.
