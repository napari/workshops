**Level:** Intermediate | **Duration:** ~4 hours | **Python required**

This workshop teaches you how to extend napari's functionality through scripting
and custom code. You will create interactive widgets with magicgui, respond to
layer events, handle mouse interactions, and customize napari's appearance —
bridging the gap between using napari as a GUI application and developing custom
analysis tools.

# Prerequisites

- Completing the [installation instructions](#extend-setup)
- Comfortable writing Python functions
- Basic familiarity with NumPy and scientific Python libraries
- Basic usage of jupyter notebooks and the command line
