**Level:** Beginner-intermediate | **Duration:** 90 minutes or ~4 hours | **Some scripting experience helpful**

This workshop teaches you how to extend napari's functionality through scripting
and custom code. You'll learn your way around the napari GUI, control the viewer
from Python, set physical scales and units, work with cloud-native formats like
OME-Zarr, build interactive widgets with magicgui, respond to layer events and
mouse interactions, and package your custom tools as pip-installable napari plugins.

Choose the schedule that fits your session:

- [90-minute schedule](#extend-schedule-90)
- [Half-day schedule (~4 hours)](#extend-schedule-360)

## Prerequisites

- Completing the [installation instructions](#extend-setup)
- Some scripting experience - Python scripts, ImageJ/Fiji macros, or similar
- If doing the 90-minute session: comfort navigating the napari viewer
	([Introduction to napari: with the App](#intro-overview) or equivalent)
